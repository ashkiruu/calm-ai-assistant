# Archived derived artifacts

`legacy_vector_db_raw_pdf_2026-07-31/` is the original prototype Chroma
database. It was archived, not deleted, because the prototype indexed the same
raw DepEd SDRRM PDF into all three hazard collections. That database is not
valid evidence of hazard or context isolation and must not be used for CALM
evaluation.

Build the next index only from
`corpus/retrieval/runtime_units.jsonl`. During internal corpus review,
`corpus/retrieval/review_candidate_units.jsonl` may be used in an explicitly
labelled non-production mode.
